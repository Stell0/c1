## Time budget on this host

- Reads at B2, B3 exceeded the 30,000 ms query time budget and returned 503 `C1-QY-053` with no partial page; B1 completed within it.
- With 5490 readable resources the response was 503 `C1-QY-053`. The candidate limit (422 `C1-QY-052`) is evaluated after the provisional candidate snapshot, which already exhausted the time budget here, so this run did not reach it.
- Per-request cost grows with the number of readable resources: C1 reads candidate content in per-class chunks and checks each candidate with OpenFGA (column above).
