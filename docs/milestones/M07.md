## 2. Goal and boundaries

**Observable result.** `POST /v1/context` returns, for an anchor and declared topics under a versioned data-only path profile, a Markdown package and an equivalent structured package built from one authorized selection: interpretation, orientation paths, self-contained facts with values, units, conditions, time, review state and origin, available excerpts, resolvable citations, provenance that separates original sources from importing activities, disagreements, gaps for requested fields, and budget bounds with signed continuation. The cross-project-batteries fixture shows PaperTrader and Robotelier producers sharing one canonical Tesla company and a third consumer obtaining battery context without choosing a project, without AI credentials, and without a battery that lacks the Tesla keyword being lost or an unrelated product being included.

**In scope.** Request grammar; context profiles as data with allowed typed paths; controlled topic scheme (`topics` profile) and alias resolution with explicit ambiguity; selection, grouping, deterministic ordering, evidence units; budget and continuation; Markdown and structured renderers; citation encoding; the fixture with golden outputs.

**Out of scope.** Natural-language query planning, semantic or vector search, LLM summaries, automatic synonym expansion, software target sets and the four software task profiles (M08–M11; this milestone leaves declared extension points for them in the profile schema without implementing them), browser preview (M12).

**Invariants touched.** AGENTS.md §6.1 (exact keywords unchanged; graph context is a separate explicit mode with declared paths; report ambiguity and matched paths), §6.2 (immediately usable material; same selection for both formats; never claim unavailable information does not exist; budgeting preserves qualifications and conflicts; no inference, no LLM), §5.3 (hidden edges, evidence, titles, excerpts, and topic labels never enter the package or its explanations).

Excerpts and citations require an independently readable complete dependency chain. | Spec §6.2; AGENTS.md §§5.3, 6.1–6.2; M05 traversal and M06 part contract. |
| D6 | **Evidence units, measurements, disagreement, and duplicate imports.** A budget unit groups a matched node and predicate with all claims, qualifiers, and evidence. A measurement is a separately typed Entity referenced by an ordinary authorized assertion from the quantity assertion (`measurementRef`); unit, conditions, and measured-on facts are ordinary assertions whose subject is that Measurement, so each link is independently authorized. Report disagreement only when a predicate is declared single-valued, valid-time intervals are known and overlap, and units/conditions are comparable. Different targets alone do not imply exclusivity; incomparable or unresolved differences remain separate claims without a conflict conclusion. Original-source counts use unique Source IDs, independently of source revision. Count imports only from explicit `prov:wasGeneratedBy` Activity records that represent source-import events; ChangeSet/application recording events are not imports or corroboration. | AGENTS.md §§4.1, 6.2; PROV-O; M04 validation semantics. |
| D7 | **Ordering.** Select and order whole units deterministically from the authorized set; citation numbers are globally stable across continuation pages. The rendered selection/order is deterministic for the same request semantics, knowledge revision, profile, and relevant bindings. The signed cursor itself is transport-volatile because it contains expiry and HMAC; compare its decoded semantic position and dependency checkpoint, not its bytes. | Spec §6.3; PLAN M07-T06. |
| D8 | **Budget and continuation.** The maximum is the UTF-8 byte length of the complete emitted Markdown document, including variable text, source lists, gaps, bounds, footer, and actual signed cursor. Structured output mirrors the same selected page, but its JSON wire size is not the budget. Select the longest contiguous whole-unit prefix that fits. If even the first unit cannot fit, return 422 `C1-CX-010` with minimum required bytes; never emit a zero-progress cursor. Continuations reauthorize the current selection and validate a semantic checkpoint over complete prefix unit contents and relevant dependency bindings. Finalize the workflow head within each request; unrelated post-page-one changes do not invalidate a continuation when they do not affect its selected prefix. | AGENTS.md §§5.3, 6.2; PLAN M07-T06/T07. |
| D9 | **Citations and provenance.** A part citation requires a readable explicit ordinary assertion `Document dcterms:source Source`, with the full evidence/part/source chain independently authorized and M06 revision/selector checks satisfied. Preserve Source version separately from Document/evidence version. If any link is missing or unreadable, omit citation and excerpt without explaining a hidden dependency.
