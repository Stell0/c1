## 2. Goal and boundaries

**Observable result.** A new contributor clones the repository, runs one bootstrap command and one check command without any AI credential, and can read from the README and roadmap exactly which statements are approved requirements, proposed mechanisms, and unimplemented plans.

**In scope.**
- Versioned, attributed local baseline with content hashes and the software-extension addendum.
- README distinguishing intended from implemented capabilities.
- Development harness: dependency lock, lint, format check, type check, unit tests, secret scan, baseline consistency check, one `make check` entry point.
- CI entry point that runs the same check.
- Plan and report conventions (`docs/milestones/README.md`, templates).
- ADRs for the M00 choices and a list of genuinely open implementation choices.
- `LICENSE` (Apache-2.0) and placeholder `NOTICE`.

**Out of scope.** Any product code, HTTP endpoint, backend container, fixture data, schema, or dependency beyond the harness. `src/c1` contains only a package marker and a version string. No milestone beyond M00 is started.

**Invariants touched.** AGENTS.md §9 (no invented repository state, secret hygiene, scoped changes) and the no-AI obligation (A01 partial: only the harness is claimed to run without AI credentials).

## 7. Recovery and security

| Failure point | Behavior |
|---|---|
| PyPI unreachable | `make bootstrap` fails; record `NOT_RUN` with the error; do not vendor packages. |
| `uv.lock` drift | `uv sync --frozen` fails; regenerate deliberately with `uv lock` and record the change. |
| Baseline check disagrees with PLAN.md | Fix the document that is wrong; never relax the check to pass. |
| Secret scan finding | Remove the value, rotate it if real, then re-audit the baseline. |

Rollback is `git revert` of the M00 commits. No permissions, services, or credentials are involved. The synthetic secret exists only in a temporary directory at test runtime; `.env` is ignored.

## 9. Implementation clarifications (2026-09-25)

The implementation contract above retains the roadmap requirements, with the two explicit precedence corrections below. [ADR-0001](../decisions/ADR-0001-runtime.md) records `uv lock --check` before frozen sync because `--frozen` alone does not check metadata drift, plus isolated build constraints. [ADR-0002](../decisions/ADR-0002-harness-tooling.md) records the rejecting offline secret-check wrapper and the clean-start `--worktree` snapshot mode used before a real commit is authorized.

Two plan corrections follow source precedence without weakening a gate: the original T04 prohibited IN_PROGRESS/VERIFYING unless a report already said VERIFIED, while W7 and higher-priority PLAN.md §2 allow those intermediate states. T04 now applies the verified-report requirement only to VERIFIED claims. Section 8 originally allowed closure with CI NOT_RUN, conflicting with PLAN.md §2 and AGENTS.md §11; it now explicitly requires remote CI PASS, and the gate remained BLOCKED until those checks passed (see the report). The local-source override makes repository integrity the baseline check; no new cloud attestation is claimed or requested.
